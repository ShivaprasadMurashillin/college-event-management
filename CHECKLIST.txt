⚠️  COMMON ISSUES & SOLUTIONS:

Issue: "Cannot connect to database"
→ Make sure MySQL Workbench can connect
→ Verify password in backend\.env is correct
→ Check database 'college_events' exists

Issue: "Port 5000 already in use"
→ Run in PowerShell:
   Get-NetTCPConnection -LocalPort 5000 | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }

Issue: "Port 3000 already in use"
→ Run in PowerShell:
   Get-NetTCPConnection -LocalPort 3000 | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }

Issue: Google Login doesn't work
→ That's OK! Google OAuth needs setup (optional for now)
→ You can still test the UI and other features
→ See QUICKSTART.md for Google OAuth setup later
