WHAT IF YOU DON'T KNOW THE PASSWORD?
═══════════════════════════════════════════════════════════════════

Option A: Check MySQL Workbench Stored Connections
   1. Open MySQL Workbench
   2. Click "Database" → "Manage Connections"
   3. Select your connection
   4. Click "Store in Vault" or "Store in Keychain"
   5. This shows or lets you reset the password

Option B: Reset MySQL Root Password
   (Advanced - Google: "reset mysql root password windows")

Option C: Create New MySQL User
   In MySQL Workbench, run:
   
   CREATE USER 'eventuser'@'localhost' IDENTIFIED BY 'event123';
   GRANT ALL PRIVILEGES ON college_events.* TO 'eventuser'@'localhost';
   FLUSH PRIVILEGES;

   Then in backend\.env, change:
   DB_USER=eventuser
   DB_PASSWORD=event123
